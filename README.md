# Learning Practice 9: Enhancing Testing with Large Language Models

This repository contains a completed **AI-assisted worked example** for North Vacation Booking, plus the supplied application. See [the report](REPORT.md) for all seven steps and [the assignment](Assignment.md) for the original instructions.

## Authorship and scope

Codex generated the example initial ideas, prompt responses, evaluations, final cases, and reflection in one conversation on November 24, 2026. The student reported having no pre-existing test ideas. Therefore Step 1 is an example baseline, not evidence of independent human work completed before AI use. The review is AI-assisted; it does not establish that the student personally verified the cases. This distinction matters because the assignment explicitly requires both activities.

The two responses are complete responses composed by the same assistant in this conversation, not transcripts from separate, context-isolated model sessions. The assistant had already read the requirements before producing the general response. The comparison illustrates prompt specificity but is not a controlled experiment.

No application tests were executed, and no pass/fail results are claimed. The report designs tests against the supplied requirements. The starter application has implementation gaps described in the report. Application source is preserved; generated build metadata and a downloaded-file metadata artifact are excluded from version control.
